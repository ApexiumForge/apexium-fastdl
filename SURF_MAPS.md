# Combat Surf map pack

Five classic Counter-Strike 1.6 maps: `surf_ski_2`, `surf_green`, `surf_ninja`, `surf_egypt`, `surf_simpsons_final`.

Sources:
- [Surf Map Archive](https://surfmaparchive.com/): surf_green, surf_ninja and surf_egypt packages.
- [CS16Planet Surf collection](https://cs16planet.ru/karty-cs-16/surf/): surf_ski_2 (package credits supermario) and surf_simpsons_final (rinkon).
- [Half-Life map resource mirror](https://www.half-life.fr/cs/mapsmirror/gfx/env/): missing desert2 sky faces, plus the mirror's sound/ambience/fallscream.wav resource for Egypt.

Original BSP bytes are preserved. Resource files were validated for Linux filename case. The Simpsons loose waterrun.wav is also supplied at sound/ambience/waterrun.wav, which the map references. Green and Simpsons embed their non-stock textures; the other maps use standard Valve/Counter-Strike WAD textures.

These community maps and resources remain the work of their respective authors. This repository mirrors game downloads for the Torbeshi server; it does not claim authorship of the maps.
