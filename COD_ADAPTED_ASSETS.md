# Adapted CoD assets

These models and sounds came from the user-supplied `COD MW4 Mod.zip` (ByM CoD 2016), SHA256 `f95dbd6953b5a507b436339a025ad251e9bdc2cc5ef8a20dd847b2bc3d28543b`.

Model bytes are unchanged. Katana and Wolverine view models have nine knife animation sequences. Missing model-event sound paths are supplied as copies of the pack's existing WAV files. The server uses newly written adaptations for the installed O'Zone/TheDoctor0 API; none of the pack's compiled AMXX, EBot or Metamod binaries are installed.
